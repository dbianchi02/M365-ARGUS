# ARGUS — Automated Report & Governance Utility Suite

> **Status: 0.1.0-beta1, in development.** Cmdlets are scaffolded; the engine, data layer, checks and report are being built in phases (see [CHANGELOG](CHANGELOG.md)).

ARGUS is a PowerShell module that runs **read-only governance checks** against a Microsoft 365 tenant, computes a weighted **Governance Score** and produces a self-contained **HTML report** (plus JSON and optional CSV) listing every check, what was found and how to fix it.

## What ARGUS is

- A **governance / hygiene** assessment: identity lifecycle, guests, app credentials, licences, Microsoft 365 Groups & Teams, SharePoint, Exchange.
- **Strictly read-only**: it never writes, updates or deletes anything in the tenant. Remediation is text and sample code in the report, never executed.
- Cross-platform: PowerShell 7.2+ on Windows, macOS and Linux.
- Lightweight: only `Microsoft.Graph.Authentication` is required. `ExchangeOnlineManagement` and `PnP.PowerShell` are optional.

## What ARGUS is not

- Not a security baseline: no CIS / CISA / MFA / Conditional Access / Defender checks. Use dedicated tools (for example Maester) for that.
- Not a remediation tool.

## Quick start

> Available on the PowerShell Gallery from 0.1.0-beta1.

```powershell
Install-Module ARGUS -AllowPrerelease -Scope CurrentUser
Connect-Argus                     # interactive, recommended role: Global Reader (+ Reports Reader)
Invoke-Argus                      # runs all checks, writes HTML + JSON to ./output and opens the report
```

## Public cmdlets

| Cmdlet | Purpose |
|---|---|
| `Connect-Argus` | Connect Graph (and optionally Exchange Online / SharePoint) with read-only scopes. |
| `Disconnect-Argus` | Disconnect the sessions opened by ARGUS. |
| `Test-ArgusPrerequisite` | Modules, connections, scopes, licences and which checks would be skipped. |
| `Get-ArgusRequiredPermission` | Permissions per check or aggregated (`-AsAppPermission` for app registrations). |
| `Get-ArgusCheck` | List the check catalogue. |
| `New-ArgusConfig` | Write a configuration file with defaults. |
| `Invoke-Argus` | Run the checks and write the report. |
| `Export-ArgusReport` | Re-render the HTML report from a results JSON file. |
